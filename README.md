# Cinematic Anime Photo

An installable Codex skill for transforming photos into original cinematic anime scenes with luminous skies, atmospheric lighting, rich color, and detailed backgrounds.

## Use it

Install the `cinematic-anime-photo` folder as a Codex skill, attach a photo, then ask:

> Use `$cinematic-anime-photo` to turn this photo into a cinematic anime scene while preserving the subject and composition.

The skill uses the built-in image generation tool by default and keeps the original photo unchanged.

If a user asks for a “Makoto Shinkai-like” image, the skill translates that request into general visual traits such as luminous skies, saturated twilight color, detailed backgrounds, and atmospheric light instead of copying a living artist's exact signature style.

## Download it

On GitHub, choose **Code → Download ZIP**, extract the archive, and install the folder that contains `SKILL.md` as a Codex skill.

In Codex, you can also ask:

> Use `$skill-installer` to install the GitHub repository `eddyrexton-a11y/cinematic-anime-photo` from its repository root (`.`).
